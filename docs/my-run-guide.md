# Run Guide

## Prerequisites
- JDK 17 or later (`java` and `javac`)
- Python 3.9 or later
- Git

## How to run
From the repository folder, run:

```
python3 run.py demo
```

On Windows, you can use `py -3 run.py demo` instead.

## What the demo does
The demo compiles the Java code into a temporary folder and runs a sample library loan scenario.
It shows the borrowing limits for students and faculty, a catalog search, a loan with its due date,
the return, and the overdue fee calculation.
